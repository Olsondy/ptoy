# UI 原型

本目录统一保存可独立预览的 HTML，直接用浏览器打开即可，无需安装依赖或启动应用服务。样式、脚本及字体均内嵌，原型不访问正式 API、麦克风或模型，不参与应用构建。

- [invite-age.html](invite-age.html)：当前邀请入口方案；精简文案，同屏确认已满 18 周岁，琥珀色确认区。右下角“原型操作”可填入演示码、切换验证结果和重置。
- [invite.html](invite.html)：早期邀请码流程原型，保留状态审查面板和模拟通话，供历史对照。

演示邀请码：`7K2M-9Q4R-X6WP-3T8N`。年龄确认仅演示用户声明，不提交信息。旧邀请码原型使用独立 localStorage 模拟会话，可通过面板清除。

后续原型继续放在本目录，`apps/web` 只保留正式应用代码。原型修改与正式功能接入分别进行。
