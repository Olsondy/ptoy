# 采用级联式半双工 + 可打断，而非端到端全双工

状态：accepted · 2026-10-23

语音链路由 ASR → LLM → TTS 三个独立模型串联，靠 VAD 实现打断，而不是用一个模型同时听和说（如 Moshi、GPT-4o 原生语音）。原因：本地 16GB 显卡上没有能同时满足中文角色对话质量、自定义音色和情绪表达的端到端模型；级联方案的每一段都可以单独替换和压测。

## Consequences

打断不会自然发生，必须让每一段都能被取消，并按实际播放到的位置截断对话历史。这部分由 LiveKit Agents 承担（见 [0002](0002-livekit-transport-and-agent-framework.md)）。
